# Todo App

A full-stack todo application with a soft brown color theme, built in an Nx monorepo.

## Tech Stack

- **Frontend:** Next.js, Tailwind CSS, shadcn/ui
- **Backend:** NestJS
- **Database:** PostgreSQL with Prisma ORM
- **Monorepo:** Nx

## Getting Started

```bash
pnpm install
```

## Running the App

```bash
# Start all services
pnpm serve

# Start frontend only
pnpm serve-frontend
```

## Features

- Add, complete, and delete todos
- Filter todos by status (all, active, completed)
- Soft brown color theme
- Internationalization (i18n) support
- SEO-ready with sitemap, robots.txt, and LLM-friendly text files
- Accessible UI components via shadcn/ui
